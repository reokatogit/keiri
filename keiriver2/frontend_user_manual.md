# 非エンジニア向け Web画面操作マニュアル（サンプル）

## できること
- ファイルのアップロード（Excel/CSV）
- 集計・名寄せ処理の実行
- 結果ファイルのダウンロード
- 顧客リストやマッピングの編集（Excel感覚で）

---

## 1. ファイルアップロード
1. 画面の「ファイルを選択」ボタンをクリック
2. 対象のExcelまたはCSVファイルを選択
3. 「アップロード」ボタンを押す
4. アップロードが完了すると、処理が自動で始まります

## 2. 処理状況の確認
- 画面上に「処理中」「完了」などのステータスが表示されます
- エラーがあれば、画面に内容が表示されます

## 3. 結果ファイルのダウンロード
- 「ダウンロード」ボタンを押すと、集計済みのExcel/CSVファイルがダウンロードできます

## 4. 顧客リスト・マッピングの編集
1. 「顧客リスト編集」または「マッピング編集」ボタンを押す
2. 現在のリストがExcel形式でダウンロードされます
3. Excelで編集し、保存（CSV形式）
4. 画面の「アップロード」から再アップロード
5. 反映後、すぐに新しい内容で処理されます

---

## よくある質問
- **Q. Excelが開けない/保存できない**
  - → ファイル形式が「CSV UTF-8」になっているか確認してください
- **Q. エラーが出た場合は？**
  - → 画面の指示に従い、ファイル内容や形式を確認してください
- **Q. どのブラウザでも使える？**
  - → Chrome, Edge, Safari, Firefox で動作します
