# keiri（経理自動化ツール）

## 概要

このリポジトリは、経理業務の自動化・効率化を目的としたPythonベースのツール群です。主にExcelやCSVファイルから売上・金額データを抽出・正規化し、集計・名寄せ・出力までを自動で行います。

## 主な機能

- Excel/CSVファイルからのデータ抽出（複数シート対応）
- 列名・値の正規化（表記ゆれ対応、AI名寄せ機能）
- 「小計」「合計」など集計行の自動除外
- 金額・数量・単価などの自動判定
- 部署・下請け・店舗ごとの集計・出力
- 月次・年次の自動レポート生成（CSV/Excel）
- ファイルの重複排除・アーカイブ
- エラー・未対応データのロギング

## 主要ディレクトリ・ファイル構成

- `keiriver2/` : メインの処理ロジック・ユーティリティ群
  - `main.py` : メイン処理エントリポイント
  - `processor.py` : データ抽出・正規化・集計のコアロジック
  - `config.py` : 設定値
  - `logger.py` : ログ出力
  - `watch_folder.py` : フォルダ監視・新規ファイル検出
  - `notifier.py` : 通知機能
  - `mapping_store.csv` : 名寄せ用マッピングストア
- `crosscheck_project/` : クロスチェック・検証用サブプロジェクト
- `output/` : 出力ファイル（CSV/Excel）
- `log/` : ログファイル
- `requirements.txt` : 必要なPythonパッケージ

## 使い方

1. 必要なPythonパッケージをインストール
   ```powershell
   pip install -r requirements.txt
   ```
2. `keiriver2/main.py` を実行
   ```powershell
   python keiriver2/main.py
   ```
3. `watch` フォルダに対象ファイルを配置すると自動で処理され、`output` フォルダに集計結果が出力されます。

## 主な仕様

- 列名・値の正規化は `processor.py` 内で実施
- 「小計」「合計」などを含む行は自動で除外
- 金額列はキーワードやパターンで自動判定
- 名寄せはAI（OpenAI API）を利用可能（APIキー要設定）
- エラーや未対応データは `log/` に記録

## 環境
- Python 3.10 以上推奨
- Windows 環境で動作確認済み
